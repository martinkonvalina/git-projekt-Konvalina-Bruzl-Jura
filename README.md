# Web SPŠ Třebíč

Jednoduchá webová stránka Střední průmyslové školy Třebíč. Web představuje školu, její studijní obory a kontaktní údaje.

## Autoři

- Lukas Bruzl

## Použité technologie

- HTML
- CSS
- JavaScript

## Funkce webu

- úvodní stránka školy,
- informace o škole,
- přehled studijních oborů,
- kontaktní údaje,
- kontaktní formulář s potvrzením o odeslání.

## Návod k použití

1. Stáhněte nebo naklonujte tento repozitář.
2. Otevřete soubor `index.html` ve webovém prohlížeči.

Projekt je možné spustit také pomocí jednoduchého lokálního serveru:

```bash
python -m http.server 8000
```

Poté otevřete v prohlížeči adresu:

```text
http://localhost:8000
```

Kontaktní formulář zobrazí potvrzovací hlášku, ale data se zatím neodesílají na skutečný server.
